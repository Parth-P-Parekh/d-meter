# Curated Parity Corpus

`manifest.json` is intentionally not committed until approved frames and baseline outputs are supplied. Start from `manifest.example.json`.

Every image requires a production-baseline JSON produced by the known-good MPK. Human annotations may be stored separately for future accuracy work, but do not replace the baseline in this parity phase.

Frame IDs and image checksums are immutable. Do not overwrite a baseline when a pipeline changes; create a new corpus version instead.
